# AUTOPROFI — главная по макету

> **Исполняется в текущей сессии.** План написан как рабочий чеклист: полный код приведён для общих компонентов, секции описаны спецификациями блоков со ссылкой на эталонный макет. Проверка — скриншотами и сверкой с макетом, потому что вёрстку не покрыть модульными тестами.

**Goal:** Привести главную страницу к макету `design/extracted/export/1-glavnaya.html` — девять секций поверх уже работающего каталога.

**Architecture:** Данные уже текут из базы, адреса и разметка готовы. Меняется только оформление. Общие элементы — обёртка секции, кнопки, чипы, поля — выносятся в набор компонентов, чтобы страницы каталога потом переиспользовали их без переписывания.

**Tech Stack:** Next.js 16 App Router, TypeScript strict, Tailwind CSS 4, токены из `docs/design-tokens.md`.

## Global Constraints

- Шрифты только со своего домена, внешние CDN запрещены
- TypeScript strict, `any` запрещён
- Тексты на русском, `lang="ru"`
- Город в заголовке допустим на главной, но не на страницах каталога
- Сообщения коммитов на русском, формат `тип: описание`
- Смотреть результат через `npm run build && npm run start` — режим разработки с файловой базой не работает
- Перед сборкой убедиться, что нет замка: `rm -f .pgdata/postmaster.pid`

## Task 1: Набор общих компонентов

**Files:** Create `src/components/ui/section.tsx`, `src/components/ui/button.tsx`, `src/components/ui/chip.tsx`, `src/components/ui/arrow-link.tsx`

Секции чередуют тёмный и светлый фон, и каждая имеет одинаковые отступы и максимальную ширину. Без общей обёртки это разъедется на третьей же секции.

```tsx
// src/components/ui/section.tsx
import type { ReactNode } from 'react'

type Tone = 'dark' | 'light'

const TONES: Record<Tone, string> = {
  dark: 'bg-bg text-ink',
  light: 'bg-paper text-ink-dark',
}

/**
 * Обёртка секции главной.
 *
 * Секции чередуют тёмный и светлый фон — это ритм страницы, заданный
 * макетом. Отступы и предельная ширина одинаковы у всех, поэтому
 * держатся в одном месте.
 */
export function Section({
  tone = 'dark',
  children,
  className = '',
}: {
  tone?: Tone
  children: ReactNode
  className?: string
}) {
  return (
    <section className={`${TONES[tone]} ${className}`}>
      <div className="mx-auto w-full max-w-[1400px] px-6 py-20 md:py-28">{children}</div>
    </section>
  )
}

/** Надзаголовок: мелкий, заглавными, с широкой разрядкой. */
export function Eyebrow({ children }: { children: ReactNode }) {
  return (
    <p className="text-[11px] uppercase tracking-[0.2em] text-ink-dim">{children}</p>
  )
}

/** Заголовок секции — Unbounded, отрицательный трекинг. */
export function SectionTitle({ children }: { children: ReactNode }) {
  return (
    <h2 className="mt-4 font-[family-name:var(--font-display)] text-[34px] leading-tight tracking-[-0.03em]">
      {children}
    </h2>
  )
}
```

```tsx
// src/components/ui/arrow-link.tsx
import Link from 'next/link'
import type { ReactNode } from 'react'

/** Призыв к действию текстовой ссылкой со стрелкой — основной приём макета. */
export function ArrowLink({
  href,
  children,
  muted,
}: {
  href: string
  children: ReactNode
  muted?: ReactNode
}) {
  return (
    <span className="inline-flex items-baseline gap-3">
      <Link href={href} className="text-accent hover:text-accent-hover">
        {children} <span aria-hidden>→</span>
      </Link>
      {muted ? <span className="text-sm text-ink-dim">{muted}</span> : null}
    </span>
  )
}
```

```tsx
// src/components/ui/button.tsx
import Link from 'next/link'
import type { ReactNode } from 'react'

const BASE = 'inline-flex items-center justify-center rounded-lg px-5 py-3 text-sm font-semibold transition-colors'

const VARIANTS = {
  solid: 'bg-accent text-white hover:bg-accent-hover',
  outline: 'border border-line text-ink hover:border-ink-muted',
  pill: 'rounded-full bg-accent text-white hover:bg-accent-hover',
} as const

export function Button({
  children,
  variant = 'solid',
  href,
  className = '',
  type = 'button',
}: {
  children: ReactNode
  variant?: keyof typeof VARIANTS
  href?: string
  className?: string
  type?: 'button' | 'submit'
}) {
  const styles = `${BASE} ${VARIANTS[variant]} ${className}`
  if (href) {
    return (
      <Link href={href} className={styles}>
        {children}
      </Link>
    )
  }
  return (
    <button type={type} className={styles}>
      {children}
    </button>
  )
}
```

```tsx
// src/components/ui/chip.tsx
import type { ReactNode } from 'react'

/** Чип характеристики: тип шара, нагрузка, масса. */
export function Chip({ children }: { children: ReactNode }) {
  return (
    <span className="rounded border border-line px-2 py-1 text-xs text-ink-muted">{children}</span>
  )
}

/**
 * Бейдж наличия.
 *
 * Зелёный против янтарного — не украшение: в каталоге рядом стоят
 * товары с отгрузкой сегодня и позиции под заказ на 1–6 месяцев.
 */
export function StockBadge({ inStock, children }: { inStock: boolean; children: ReactNode }) {
  return (
    <span
      className={`rounded px-2 py-1 text-xs font-semibold ${
        inStock ? 'bg-in-stock/15 text-in-stock' : 'bg-on-order/15 text-on-order'
      }`}
    >
      {children}
    </span>
  )
}
```
