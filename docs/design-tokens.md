# AUTOPROFI — дизайн-токены

Извлечено из `design/extracted/export/5-design-system.html` 11 августа 2026.
Это источник правды для конфига Tailwind. При расхождении вёрстки и макета — правда здесь.

## Шрифты

| Роль | Гарнитура | Где |
|---|---|---|
| Заголовки | **Unbounded** | H1–H3, крупные числа, логотип |
| Текст и интерфейс | **Wix Madefor Text** | абзацы, кнопки, таблицы, подписи |

Обе есть в Google Fonts с кириллицей.

**Подключать только со своего домена.** Загрузка с `fonts.googleapis.com` добавляет обращение к внешнему хосту, замедляет первую отрисовку и создаёт зависимость от сервиса, недоступность которого мы не контролируем. Кладём `.woff2` в `public/fonts/`, объявляем через `next/font/local` с `display: swap`.

Подключать только используемые начертания и только кириллицу с латиницей — полный набор Unbounded весит в разы больше, чем нужно.

Основное значение — `0.2em` при кегле `11px`. Именно так набраны «КАТАЛОГ», «АКЦИИ», «ВЫ В ПЕТЕРБУРГЕ».

## Правило языка страниц

Из спецификации, раздел 5. При вёрстке соблюдать неукоснительно:

**Главная** — журнальная подача. Одна мысль на секцию, заголовок 2–5 слов, одно предложение под ним, никаких маркированных списков, крупные числа, много воздуха, призыв текстовой ссылкой со стрелкой.

**Каталог, кузова, карточка товара** — инструментальная подача. Плотно, таблицы, чипы характеристик, цены, фильтры. Здесь человек выбирает, а не впечатляется.

## Что взять из экспорта при вёрстке

Файлы в `design/extracted/export/` — это React-бандлы: разметки в них нет, всё рисуется скриптом. Как код они не годятся, как эталон внешнего вида — да.

Порядок работы: открываем макет рядом с собираемой страницей, сверяем визуально, значения берём отсюда.
