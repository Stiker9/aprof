## Предлагаемые шаблоны (на согласование)
- **Марка:** «Фаркопы на Kia: 400 моделей от X ₽. Подбор по кузову и году, установка за один визит в Санкт-Петербурге, доставка по России.»
- **Модель:** «31 фаркоп на Lada Kalina от X ₽. Подбор по кузову и году, установка за один визит в Санкт-Петербурге, доставка по России.»
- **Кузов, товар — title:** хвост «— купить с установкой» убирать, если title длиннее 60 знаков.
- **Товар — description:** «Фаркоп GALIA T026A на Toyota Hiace 1996–2005: 18 990 ₽, в наличии. Шар F, 2000/75 кг. Установка в СПб за один визит, доставка по России.» — собирается из данных, не из текста поставщика.

Город в title каталога пока не добавляем: решим по Вордстату, есть ли спрос на «фаркоп на X спб».
