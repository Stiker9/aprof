# Картинки товаров

Собирает изображения фаркопов с сайтов заводов-изготовителей и кладёт их
в `public/images/products`.

```bash
npx tsx scripts/images/run.ts --plan        # посчитать, ничего не качая
npx tsx scripts/images/run.ts               # обойти все источники
npx tsx scripts/images/run.ts --source=treiler --limit=20
npx tsx scripts/images/generate.ts          # собрать список для сайта
npx tsx scripts/images/sheet.ts             # контактный лист для просмотра
```

## Зачем

В выгрузке поставщика у каждого товара есть снимки, и пользоваться ими
нельзя: они несут замощённый по всей площади знак «ФАРКОП.РФ» с чужим
телефоном. Это реклама конкурента на нашем сайте.

Знак не снимаем. Удаление информации об авторском праве — ст. 1300 ГК,
отдельный состав помимо самого использования, компенсация по ст. 1301 до
5 млн независимо от убытков.

Поэтому источник — сайт того завода, чьё изделие мы продаём, где та же
деталь выложена без чужого знака. Это его собственная реклама товара,
который мы у него же и берём.

Оговорка, которую надо держать в голове: снимок завода — всё равно его
авторское право. Практика отрасли, интерес самого завода и мизерный риск
на нашей стороне, но это именно практика, а не разрешение. Снимается
одним письмом — попросить у завода доступ к фотоархиву. Заказчик писал
поставщикам, ответа нет; заводам напрямую ещё не писали.

## Как устроено

```
run.ts          конвейер: что нужно → обход → выбор кадра → запись
generate.ts     манифест → src/catalog/product-photos.ts
sheet.ts        манифест → контактный лист HTML
core/http.ts    вежливая загрузка: пауза, кэш, честный User-Agent
core/match.ts   ключ артикула для сопоставления
core/classify.ts чертёж это или нет
core/store.ts   webp ≤1000px + манифест
sources/*.ts    по файлу на завод
```

`data/product-photos.json` — для каждого артикула записано,
с какой страницы взята картинка и по каким числам классификатор принял
решение. Через полгода это единственный способ ответить, откуда у нас
конкретное изображение.

### Что считается годным

Классификатор умеет одно: отличить чертёж или 3D-рендер на белом от
всего остального. Это и есть то, что нам нужно, — в таком кадре только
изделие.

Фотографии автоматически не публикуются. На них в кадр попадают чужие
номера, рамки номера с телефонами автосалонов и вывески: на снимке
Трейлера к артикулу 2020 читается «MAJOR AUTO … 229-46-46», на снимке
Лидер-плюс к A201-A — телефон ростовского дилера Honda. Такое ставить в
каталог нельзя, и увидеть это может только глаз.

Всё, что не чертёж, попадает в манифест с `approved: false` и ждёт
просмотра в контактном листе. Чтобы выложить — поставить `true` и
перезапустить `generate.ts`.

## Как добавить завод

Один файл в `sources/`, экспортирующий объект `Source`: `discover()`
отдаёт `{ article, pageUrl, images }`, остальное делает ядро. Смотреть на
`treiler.ts` — там разобран сложный случай, когда артикула нет в адресе
и его приходится брать из заголовка.

Перед этим стоит проверить, что артикулы завода совпадают с нашими: у
GALIA, например, своя нумерация (`C0426`), а у нас распространительская
(`C076C`), и сопоставить их без таблицы соответствия нельзя.
