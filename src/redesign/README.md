# Рабочая копия главной

Адрес: `/redesign`.

Страница: `src/app/(redesign)/redesign/page.tsx`.
Корневой макет: `src/app/(redesign)/layout.tsx`.

Для редизайна меняем компоненты в этой папке, `globals.css` и `tokens.css`.
Они скопированы с текущей главной и не используются основной версией сайта.
Отдельный корневой макет позволяет менять шапку и подвал независимо.

Каталог, данные, изображения и файлы шрифтов остаются общими.
Для изменения изображений создавайте новые файлы, не заменяя исходные.
Ссылки на каталог и остальные разделы открывают существующие страницы;
логотип возвращает на `/redesign`. Это копия только главной страницы.

Страница имеет `noindex, nofollow` и не добавлена в sitemap. Это не
ограничение доступа: при публикации всей сборки адрес тоже будет доступен.
