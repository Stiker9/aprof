# Выкладка сайта на хостинг reg.ru

Сайт выкладывается статикой: папка готовых файлов, сервер ей не нужен.
Поэтому подходит обычный виртуальный хостинг.

## Куда выкладываем

| | |
|---|---|
| Хостинг | Host-0, услуга `u3637241` |
| Сервер | `server106.hosting.reg.ru` |
| Домены | `vashfarkop.ru` (главный), `vashfarkop.online` (перенаправляется) |
| Папка сайта | `~/vashfarkop.ru/public_html` |

Срок хостинга — до 07.11.2026, автопродление включено. **Следите за
балансом:** при нуле на счету автопродление не сработает и сайт
отключится.

## Как собрать

```bash
npm run build:static
```

Команда делает четыре вещи:

1. разворачивает базу, если её нет
2. собирает сайт в папку `out` — около 1,4 ГБ, 8 257 страниц
3. чинит имена файлов предзагрузки (см. ниже)
4. кладёт `.htaccess` в корень выгрузки

Собирается минут двадцать. Запускать на хостинге **не нужно и нельзя** —
там нет Node.js. Собираем у себя, заливаем результат.

Проверить, что получилось, до заливки:

```bash
node scripts/serve-static.mjs      # http://localhost:4400
```

Это файловый сервер без Next — ровно то, что будет на хостинге.

## Как залить

Файлов около 54 тысяч. По одному они будут заливаться часами, поэтому
отправляем одним архивом и распаковываем на месте.

```bash
# у себя
tar -czf site.tar.gz -C out .
scp site.tar.gz u3637241@server106.hosting.reg.ru:~/

# на сервере
ssh u3637241@server106.hosting.reg.ru
cd ~/vashfarkop.ru/public_html
rm -rf ./*                      # осторожно: стирает прежний сайт
tar -xzf ~/site.tar.gz
rm ~/site.tar.gz
```

Доступ по SSH настраивается ключом в панели reg.ru, раздел управления
хостингом. **Пароль для этого не нужен и передавать его не надо.**

## Что делает .htaccess

Лежит в `deploy/.htaccess`, копируется в выгрузку автоматически.

- адреса остаются без `.html`: `/podbor`, а не `/podbor.html`
- `www`, `http` и домен `.online` перенаправляются на `https://vashfarkop.ru`
- HTML сжимается при отдаче — страница марки весит 85 КБ текста
- картинки и стили кэшируются на год, страницы не кэшируются

## Про файлы предзагрузки

Next 16 кладёт данные для перехода между страницами вложенными папками,
а браузер просит их плоским именем через точку. На сервере Next это
расхождение разруливает сам, в статике — некому, и каждая такая просьба
даёт 404.

Сайт при этом работает: не найдя данных, браузер просто перезагружает
страницу. Но Next заранее запрашивает все ссылки в видимой части экрана
— на странице подбора это полсотни пустых запросов.

Чинит `scripts/flatten-prefetch.mjs`, он встроен в сборку. Руками
запускать не надо.

## Чего на этом хостинге не будет

Админки и приёма заявок. На Host-0 нет Node.js и PostgreSQL — только
PHP, Perl, Python и MySQL. Запускать свои программы там нельзя.

Под админку понадобится отдельный VPS, желательно из линейки ФЗ-152:
там будут телефоны клиентов, а эта площадка аттестована под хранение
персональных данных.

Схема после появления админки: сайт остаётся здесь, админка живёт на
VPS и после каждой правки обновляет файлы на этом хостинге. Оплаченный
Host-0 не пропадает.

- **Режим работы по дням** — сейчас известно только «до 20:00».
- **Рабочая почта** — `hello@vashfarkop.ru` ещё не создана.
- **Идентификация домена через Госуслуги** — с 1 сентября 2026 без неё
  недоступны операции с доменами `.ru`.

Пустые разделы (отзывы, цены установки, акции) публиковать можно: они
не показывают ничего ложного и ждут заполнения через админку.
